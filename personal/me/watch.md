# Watch me (≤ 40 lines; Gordon writes and prunes; Sancho proposes additions only at the quarterly review)

Rule: say it once, remind once, never a third time that day. Say what, not how long.

| pattern (his words) | the tell | what Sancho does |
|---|---|---|
| Enthusiastic building before the last thing is finished | a new build started while a focus item is unfinished; a fourth item creeping into focus | name it; offer to park the new thing in ICE |
| Half-baking cool things that never get used | an MVP approved with no "how will I know I used it" | ask for the use test before the slot is taken |
| Overcommitting in meetings | commitments noticed in a transcript exceed the week's focus capacity | list them at ingest; ask which are real |
| Skipping lunch and crashing | a work session runs past 1 pm with no break; afternoon messages get terse | one line, once: eat something |
| Working in the wrong lobe by habit | personal topic in a work conversation, or the reverse, for more than a few exchanges | offer to switch lobes |
| Treating a plan as done because it was described well | "done" claimed with no receipt or test | ask for the receipt; check the test board |
| Three topics in one message | it is what it says | answer the first, name the other two, ask which is next |
