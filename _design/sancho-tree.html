Where a recording ends up

Lands once in recordings/inbox/. Ingest moves it: one client → that client's transcripts/; personal → personal/recordings/; both → stays in recordings/<year>/ with a summary on each side. The ledger records the final path per rec_id.

What startup reads

CLAUDE.md, the lobe INDEX.md (FOCUS on top), recordings/STATUS.md, _queue/HEALTH.md, plus the date and a git delta. Six reads, eight lines out.

One person, one file

Lizzie is people/lizzie-mack.md once, referenced from entomat/stakeholders/ and american-icon-spirits/stakeholders/; each folder holds only what belongs to that venture.

What loads at startup

Eight reads: date, CLAUDE.md, the lobe index, recordings/STATUS.md, _queue/HEALTH.md, a git delta, personal/me/brief.md, personal/me/watch.md. Everything else, transcripts and knowledge included, loads when a question or skill needs it.
